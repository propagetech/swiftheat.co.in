# swiftheat.co.in

Website for **Swiftheat Thermal Technologies Pvt Ltd**, industrial heater
manufacturer, Plot C-262, 6th Cross, Peenya Industrial Area 1st Phase,
Bangalore 560058.

Built to the ProPage house standard: hand written semantic HTML, one stylesheet
and one script per surface, self hosted woff2 fonts, WCAG 2.1 AA audited,
schema.org structured data, path portable relative URLs, static hosting on
Cloudflare Pages.

## What is in here today

The site itself has not been built yet. This repository currently holds the
pre build material.

| Path | What it is |
| --- | --- |
| `proposal/` | Seven page client proposal, generated by `proposal-build.py`. Sales artefact, not part of the finished site. |
| `proposal/mockup/` | Working mockup of the proposed cartridge heater product page, including a live enquiry form. |
| `archive-old-site/` | The previous WordPress site as found on 25 Aug 2026: four pages plus every uploaded image at original resolution. |
| `proposal-build.py` | Regenerates the seven proposal pages. Edit the bodies in here, never the generated HTML. |

Internal research, pricing reasoning and the internal quotation are **not** in
this repository. They live in `docs/` in the working folder and are gitignored.

## Working on the proposal

Regenerate after editing `proposal-build.py`:

    python3 proposal-build.py

Serve it locally:

    cd proposal && python3 -m http.server 8123

Audit contrast before shipping any change (WCAG 2.1 AA is a house invariant):

    node ../_rebuild-kit/tools/contrast-audit.mjs http://localhost:8123

## Before the site is built

Open questions with the client, recorded so they are not lost:

1. The registered address on the old site (Plot B-132, 3rd Cross) contradicts the
   address on the company letterhead (Plot C-262, 6th Cross). Unresolved.
2. Real phone numbers are needed. The old site published `+91 12345 67890`.
3. The logo exists only as a 625 px PNG. A vector original is needed.
4. Product list is unconfirmed: immersion heaters and control systems appear on
   the old site but not in the brief; ceramic infrared and nozzle heaters appear
   in the brief but not on the old site.
5. All existing product photography is under 850 px and unusable. New photography
   is a prerequisite for go live.
